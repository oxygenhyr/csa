# 计算机协会内部管理系统

赛博朋克风格的协会成员管理系统，支持在线报名、成员展示、后台管理。

## 📁 文件结构

```
计算机协会/
├── index.html            # 首页
├── members.html          # 成员名单（公开，仅显示姓名+职位+专业）
├── register.html         # 注册报名
├── admin.html            # 管理后台（隐藏入口）
├── css/style.css         # 样式
├── js/
│   ├── supabase-config.js   # Supabase 配置（⚠️ 需修改）
│   ├── auth.js              # 认证
│   └── db.js                # 数据库
└── README.md
```

## 🚀 部署步骤（不需要谷歌账号）

### 第一步：注册 Supabase（1分钟，用 GitHub 账号）

1. 打开 [app.supabase.com](https://app.supabase.com)
2. 点击 **Sign In with GitHub**（用你的 GitHub 账号登录）
3. 点击 **New project** → 选择 Organization → 输入项目名 "csa"
4. 数据库密码自己设一个（记下来），Region 选 **Northeast Asia (Tokyo)**
5. 等待项目创建（约 2 分钟）

### 第二步：创建数据表

进入项目后 → 左侧 **SQL Editor** → 粘贴以下 SQL → 点 **Run**：

```sql
-- 创建成员表
CREATE TABLE members (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  "studentId" TEXT,
  department TEXT,
  grade TEXT,
  email TEXT,
  phone TEXT,
  skills TEXT,
  reason TEXT,
  position TEXT DEFAULT '',
  status TEXT DEFAULT 'pending',
  notes TEXT DEFAULT '',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 开启实时同步（可选，让数据自动刷新）
ALTER PUBLICATION supabase_realtime ADD TABLE members;

-- 设置行级安全策略：任何人可读已通过成员
ALTER TABLE members ENABLE ROW LEVEL SECURITY;
CREATE POLICY "公开查看已通过成员" ON members FOR SELECT USING (status = 'approved');
CREATE POLICY "管理员全部权限" ON members FOR ALL USING (true);
```

### 第三步：开启认证

1. 左侧 **Authentication** → **Providers**
2. **Email** 那一栏 → 打开开关（Enable Email provider）
3. 下方 **Confirm email** 可以关掉（避免注册需要验证邮箱）

### 第四步：配置网站

1. 左侧 **Settings** → **API**
2. 复制 **Project URL** 和 **anon public key**
3. 打开 `js/supabase-config.js`，替换：

```js
const supabaseConfig = {
  url: "https://xxxxxxxxxxxx.supabase.co",   // ← 你的 Project URL
  anonKey: "eyJhbGci...",                     // ← 你的 anon key
};
```

### 第五步：创建管理员账号

1. 左侧 **Authentication** → **Users** → **Add user**
2. 输入管理员邮箱和密码 → **Create User**
3. 用这个账号在 `admin.html` 页面登录即可

### 第六步：上传到 GitHub Pages

1. 在 GitHub 新建仓库
2. 把整个文件夹上传
3. Settings → Pages → Source 选 `main` 分支 → Save
4. 访问 `https://你的用户名.github.io/仓库名/`

## 🎯 访问方式

| 页面 | 谁用 | 怎么访问 |
|------|------|----------|
| 首页 + 注册 + 名单 | 所有成员 | 公开 URL |
| `admin.html` | **仅管理员** | 直接输入地址，导航栏无入口 |

## 🔐 隐私保护

- **公开页面**：只显示姓名、职位、专业、加入时间
- **管理员后台**：可查看全部信息（学号、手机、邮箱、年级、技能等）
- 管理员在后台编辑成员时可分配「职位」

## 🌐 本地预览

双击 `index.html` 即可在浏览器中预览（本地模式，数据存在浏览器中，无法共享）。

## 🎨 自定义

- 修改颜色：编辑 `css/style.css` 开头的 `:root` 变量
- 修改内容：编辑各 `*.html` 文件中的文字
- 修改表单字段：编辑 `register.html` + `js/db.js`
